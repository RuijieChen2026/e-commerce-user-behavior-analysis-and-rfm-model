# 电商用户行为分析与 RFM 用户分层

> 从转化漏斗诊断到用户分层，再到运营策略验证的完整数据分析项目。

**[查看完整分析 Notebook](./e-commerce-user-behavior-analysis-and-rfm-model.ipynb)**

## 项目背景

当平台从流量增长转向存量用户经营时，单纯看 PV 和订单量很难回答两个关键问题：

1. 用户在从浏览到购买的哪一步流失最严重？
2. 有限的运营资源应该优先投向哪类用户？

我选取淘宝用户行为数据，将分析拆成“发现问题—识别人群—设计策略—验证效果”四个阶段。

## 分析路径

```text
98.7 万条有效行为记录
        ↓
浏览 → 收藏 / 加购 → 购买漏斗
        ↓
基于最近购买时间和购买频次的用户分层
        ↓
针对重要唤回用户设计优惠券实验
        ↓
卡方检验判断转化差异是否显著
```

## 核心发现

### 1. 最大损失发生在“浏览→意向”

| 指标 | 结果 |
| --- | ---: |
| 浏览行为 | 884,680 |
| 收藏 + 加购 | 82,519 |
| 购买行为 | 20,171 |
| 浏览→意向转化率 | 9.33% |
| 意向→购买转化率 | 24.44% |
| 浏览→购买总转化率 | 2.28% |

用户一旦收藏或加购，后续成交意愿明显高于首层转化。因此，优先级不应只放在促销结算环节，还应检查商品首图、标题、详情页体验与流量匹配度。

### 2. 用户价值需要分层经营

我使用 Recency 和 Frequency 将购买用户划分为四类：

- **重要价值客户**：近期购买且购买频率高，适合会员权益和交叉销售。
- **重要唤回客户**：历史购买频率高，但近期沉默，是召回策略的优先人群。
- **重要发展客户**：最近有购买，但频次较低，适合通过内容和复购激励培养习惯。
- **一般维持客户**：购买时间较早且频率较低，需要严格控制触达成本。

> 原始数据没有交易金额字段，因此本项目实际使用的是 R/F 简化分层，没有人为构造 Monetary 指标。

### 3. 运营策略需要通过实验判断

针对“重要唤回客户”，Notebook 设计了一组优惠券 A/B Testing 模拟：

- 对照组转化率：2.00%
- 实验组转化率：3.00%
- 相对提升：50.00%
- 卡方检验 P-value：0.0017

该结果在模拟数据中具有统计显著性，用来演示如何将用户分层转化为可验证的运营假设。这不是真实线上实验结果。

## 业务建议

1. **优化首层转化**：围绕商品主图、详情页加载和流量匹配度建立页面级漏斗，找出高流量低意向商品。
2. **定向唤回而非全量发券**：针对高频但沉默的用户设置触达阈值，同时将券核销成本纳入 ROI 评估。
3. **经营高价值用户**：用会员权益、新品优先体验和交叉销售提升留存与生命周期价值。
4. **上线前完善实验设计**：补充样本量估算、随机化检查、实验周期、护栏指标和优惠券成本，避免只追求转化率。
